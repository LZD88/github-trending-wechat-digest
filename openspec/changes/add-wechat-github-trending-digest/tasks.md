## Workflow follow-up

- 用户提供已绑定个人微信的 Server酱 SendKey 后，在目标仓库 Secrets 中配置并执行一次 `test-binding`。
- 观察至少一次自动定时发送，确认微信送达时间、消息分段和 GitHub Actions 执行记录符合预期。
