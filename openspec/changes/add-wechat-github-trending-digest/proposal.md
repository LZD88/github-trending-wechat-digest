# Proposal

## Why

用户希望每天早上自动收到前一天 GitHub 热榜前十，减少手动浏览和筛选成本。个人微信没有面向个人账号的官方机器人接口，因此需要采用 Server酱一类已绑定微信的合规推送服务，避免直接登录个人微信带来的风控和封号风险。

## What Changes

- 新增每日 GitHub Trending 抓取与榜单整理能力，默认在北京时间每天 08:00 生成前一日热榜前十。
- 为每个项目输出排名、仓库名称与链接、项目简介、主要语言、总 Star 和榜期新增 Star；英文简介转换为简洁中文摘要。
- 新增个人微信推送能力，以 Server酱作为首个适配器，通过密钥完成绑定，不保存微信账号、密码或登录态。
- 新增可替换的推送适配器边界，为后续接入 PushPlus 等服务保留扩展点。
- 新增执行记录、幂等控制、失败重试和失败可观测信息，防止同一榜单重复发送并便于排查漏报。
- 新增可手动触发的预览/补发入口，便于首次绑定验证和故障恢复。

## Capabilities

### New Capabilities

- `github-trending-digest`: 定时获取 GitHub 日榜，生成前十中文摘要，并对榜期、排序、字段完整性及重复执行作出约束。
- `personal-wechat-delivery`: 通过已绑定个人微信的第三方推送服务安全发送榜单，覆盖配置校验、消息分段、重试、幂等和手动测试。

### Modified Capabilities

无。

## Impact

- 新增一个可由 GitHub Actions 定时运行的轻量应用及其自动化工作流。
- 外部依赖包括 GitHub Trending 页面/兼容数据源、GitHub Repository API（用于补全元数据）和 Server酱推送 API。
- 部署方需要配置 Server酱 SendKey；可选配置 GitHub Token 和摘要服务凭据。
- 将新增榜单快照与执行状态存储，用于历史追踪、幂等判断和失败诊断。
- 不直接操作个人微信客户端，不采集微信账号密码，不使用非官方微信登录协议。
